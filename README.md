# LETI Student 3.0 — native Android

Это нативный UI-проект Android Studio. Основные экраны — обычные Android View, а официальный сайт используется только для авторизации.

## Экраны
Главная / Новости / Расписание / Успеваемость / Профиль.

## Архитектура
`StudentRepository` — единая точка подключения API. Публичная документация API личного кабинета не найдена, поэтому проект не содержит выдуманных URL и не отправляет логин/пароль на сторонний сервер.

## Сборка
Android Studio -> Open -> выбрать эту папку -> Build -> Build APK(s).
